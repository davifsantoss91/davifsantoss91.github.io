Como montar o escritório dos seus agentes de IA

O app do vídeo se chama Habblaud. Ele é de graça, de código aberto e roda no teu computador: cada sessão do Claude Code (ou do Codex) vira um bonequinho trabalhando numa sala. Aqui tá como instalar e montar o espaço do jeito que eu uso.

  • Grátis e código aberto
  • Roda no teu computador
  • Claude Code e Codex

O vídeo

Não é design bonito, é a equipe trabalhando

  • O escritório

    Cada sala é um projeto, cada bonequinho é um agente.

  • Em tempo real

    Quem anda pelo corredor está levando informação de um agente pro outro.

O que ele faz

Tu bate o olho e sabe quem está fazendo o quê

  • Uma sala por projeto

    Toda pasta onde tem um Claude Code aberto ganha a sua sala. Fechou a última sessão, a luz apaga e a sala vira jardim.

  • Um personagem por agente

    Digitando na mesa é trabalhando. Mão levantada é esperando tu aprovar alguma coisa. Subagente chega pelo elevador e entrega o resultado.

  • Aprovar dali mesmo

    Com o mod instalado, tu aprova permissão, responde pergunta e manda mensagem pro agente sem procurar a janela certa.

  • Uso das contas

    No topo aparece quanto tu já gastou da sessão de 5 horas e da semana em cada conta do Claude.

Tudo roda na tua máquina, lendo os arquivos que o próprio Claude Code já grava. O Habblaud não lê senha nem manda o teu trabalho pra internet.

    Prompt · preparar

    Quero instalar o Habblaud (https://github.com/marmottajr/habblaud), o escritório virtual dos agentes do Claude Code. Eu não sei programar, então antes de cada passo me explica em uma frase o que tu vai fazer.

Se travar

Onde costuma emperrar

O escritório está vazio+

Só aparecem sessões abertas do Claude Code. Abre uma e confere em localhost:4747/api/health se a conta foi encontrada. Se as tuas contas ficam em outra pasta, pede pro Claude configurar HABBLAUD_CLAUDE_DIRS.

O uso das contas aparece "sem dados"+

Roda npm run mod:install e confere com npm run mod:status. Os números chegam depois da próxima resposta numa sessão aberta; sessão que já estava aberta precisa de /reload-plugins.

A porta 4747 já está em uso+

Já tem outro Habblaud ligado. Desliga o outro ou sobe numa porta diferente com HABBLAUD_PORT=4848.

O terminal e o aprovar pelo escritório não aparecem+

Essas funções só existem abrindo por http://localhost:4747, no próprio computador. Se tu liberou o acesso pela rede, elas desligam de propósito, por segurança.

Deu um erro e eu não entendi+

Cola o erro na conversa do Claude Code e escreve: me explica esse erro em uma frase e conserta. Quase sempre ele resolve sozinho.
